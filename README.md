# Age__Calculator

A simple and user-friendly **Age Calculator** web application that calculates a person's exact age based on their date of birth.

## 🚀 Features

* 📅 Enter your Date of Birth
* 🎂 Calculate age in **Years, Months, and Days**
* ⚡ Instant age calculation
* 📱 Simple and responsive design
* 🎨 Clean and user-friendly interface
* ❌ Handles invalid date inputs


## 📂 Project Structure

```text
Age__Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💡 How It Works

1. Enter your **Date of Birth**.
2. Click on the **Calculate Age** button.
3. The application calculates your current age.
4. Your age is displayed in **Years, Months, and Days**.
